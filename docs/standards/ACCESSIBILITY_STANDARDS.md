# Accessibility standards

Target WCAG 2.2 AA for all five surfaces as a product engineering acceptance target. Use semantic landmarks and headings, keyboard reachable controls, visible focus, accessible field labels/errors and screen-reader live status. Dialog focus traps return focus to trigger. Minimum contrast 4.5:1 text and 3:1 large text/control boundaries; do not rely on color alone. Respect reduced-motion and 200% zoom/reflow.

Validate keyboard-only core journeys including enrolment, quiz attempt, file submission, attendance and refund confirmation. Automated axe checks supplement manual screen-reader and focus testing. Captions/transcripts are required for published instructional video; images need meaningful alternative text or decorative marking. Student instructions use short steps and plain wording; quiz timing cannot create an inaccessible barrier. Public/private tables preserve header associations and provide mobile alternatives. Document issues with severity and evidence; unresolved critical access barriers block launch.

Authority: approved scope and architecture precede this standard. Apply only to the selected chunk; verify against its acceptance criteria and record evidence in its handoff.
