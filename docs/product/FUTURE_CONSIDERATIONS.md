# Future considerations

These ideas are not launch requirements, are not part of requirement coverage and must not be implemented automatically. Their presence here confers no approval.

| Possible future idea | Evidence needed before proposing scope change |
|---|---|
| Constrained parent schedule-change request workflow | Measured support demand plus operational decision ownership |
| Instalments or sibling discounts | Approved commercial policy, accounting/reconciliation design and legal review |
| Native mobile application | Demonstrated browser limitation and sustained user need |
| Additional accessible assessment formats | Course learning outcomes requiring them and secure grading design |
| Guardian invitation self-service | Verified identity/relationship proof process with abuse analysis |
| Optional class recordings | Safeguarding/privacy consent, retention and role-access design approved by humans |
| Additional achievement types | Educational evidence beyond completion, without privacy-harming ranking |
| Additional live/calendar/email providers | Reliability or commercial need sufficient to justify adapter support |
| Privacy-preserving learner analytics | Explicit approved purpose, bounded data and retention, and child-safety review |
| Deterministic-context tooling enhancements | Measured fresh-session failure or documentation scale issue |

Ideas excluded by the business model—such as a tutor marketplace, social network or autonomous tutor—require a separate explicit product decision, not opportunistic implementation.
